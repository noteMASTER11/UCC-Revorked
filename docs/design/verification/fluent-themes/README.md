# Light / Dark / Auto — проверка UI Kit

2026-10-03. Работа инлайн. Применены designly:visual-qa и план
[Fluent themes](../../../superpowers/plans/2026-10-03-fluent-themes.md).

Кнопка справа вверху использует солнце, полумесяц и совмещённый значок.
Щелчок переключает Light → Dark → Auto → Light; tooltip и доступное имя
содержат текущий режим. Auto слушает QStyleHints::colorSchemeChanged;
Unknown даёт светлую тему. Поддержка сообщения о системной теме зависит от
платформы Qt/окружения рабочего стола. Настройки рабочего стола не изменяются.
Обычная сборка сохраняет только режим интерфейса в appearance.ini,
preview хранит выбор в памяти и ничего не записывает.

FluentTheme содержит общую семантическую палитру: фон окна, карточки,
вложенные блоки, текст/метаданные, границы, акцент, выделение,
недоступные элементы и статусы. Адаптированы sidebar, навигационные значки,
селекторы, поля, кнопки, focus/hover/checked/disabled, слайдеры,
чекбоксы, переключатели, списки и Qt-диалоги цвета. Клавиши используют
сдержанный оттенок реального LED-цвета; сами аппаратные цвета сохранены.
Графики обновляют фон, оси, линии, легенды, hover, sticky marks и crosshair;
точки, диапазоны и выбранные метрики при смене темы не сбрасываются.
Смена палитры отменяет старый снимок анимации появления.

## Дополнительные исправления и рабочая сборка

- `entrance-fix`: начало и промежуточные кадры всех шести страниц в обеих
  темах (0, 40, 110 и 210 мс). Фон анимации использует текущую палитру.
- Fan/Pump на Overview применяются при выборе. Успешная ручная команда
  выключает общий режим Auto водяного блока; Auto возвращает управление
  кривым на следующем цикле контроллера. Неуспешная команда сохраняет режим.
- Применение и сохранение системных, вентиляторных и клавиатурных профилей
  использует Polkit CONTROL: активная локальная сессия работает без пароля.
- Сборка `fluent4` установлена и проверена. Полный CTest: 18/18; тесты
  read-only селекторов: 3/3. Проверки установленного D-Bus использовали
  некорректные параметры и повторную установку текущего режима Auto,
  не меняя параметры оборудования. Read-only preview по-прежнему блокирует
  аппаратные команды и запись профилей.
