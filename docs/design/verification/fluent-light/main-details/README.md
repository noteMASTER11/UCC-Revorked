# Основное + детали и селекторы Water cooler

2026-10-03. Работа инлайн, с designly:composition-director.

Выбранный пользователем [референс](selected-reference.png) реализован в Qt Widgets:
один ряд Temperature / Fan / Frequency / Power, вертикальные разделители,
отдельный приглушённый блок GPU load / P-State и VRAM load / Clock offset.
Главные данные CPU и GPU сохраняют общую линию. Единицы отделены от чисел.

В карточке Water cooler вместо значений добавлены селекторы шириной 100 px:
Fan — Auto, 20%, 40%, 60%, 70%, 80%, 90%, 100%;
Pump — Off, 7 V, 8 V, 11 V. Использованы существующие PumpVoltage-коды
Off=4, 7V=2, 8V=3, 11V=0; неподдерживаемые 12 V не добавлены.
Селекторы и кнопки выровнены по нижней линии, стрелка раскрытия общая с Profiles.
Произвольная текущая скорость отображается точно, без округления к пресету.

Read-only preview: выбор меняет только интерфейс, очередной опрос его не сбрасывает.
В обычной сборке ручные команды используют прежний API и доступны при отключённом
автоматическом управлении активного профиля. Auto в текущем API общий для Fan/Pump,
меняется в Profiles; нового независимого автоматического режима не введено.

Проверки: новый тест селекторов сначала падал на их отсутствии, после реализации
прошёл; проверены порядок опций, коды напряжения, исходное чтение без записей,
сохранение выбора и отсутствие записей в preview. Проверка сетки и плотности
CPU/GPU прошла. Обе сборки успешны, обе полные CTest-серии 16/16.
Снимки всех шести страниц в 1280×900, 1024×768 и при 150% созданы настоящими Qt Widgets
на тестовой шине D-Bus; два сеанса отрисовки прошли, по 3/3. git diff --check чист.
