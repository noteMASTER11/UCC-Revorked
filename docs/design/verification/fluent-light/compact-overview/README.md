# Компактные CPU/GPU и шкала Power

2026-10-03. Основание — снимок пользователя с избыточным пространством
в карточках. Применён designly:composition-director; работа инлайн.

- Поля CPU/GPU уменьшены с 24 до 16 px; вертикальные интервалы — 4/8 px.
- Заголовки занимают 24 px, модели 28 px (есть место для двух строк),
  температура 48 px. Температуры и разделители сохраняют общую линию.
- GPU-метаданные собраны в два ряда пар «подпись — значение». Название
  Offset (MHz) имеет tooltip с полным пояснением. Размеры главных чисел сохранены.
- В фикстуре 1280×900 высота карточек теперь не превышает 250 px;
  на 1024×768 — 270 px. До уплотнения проверка этого условия падала.
- Отдельный график Power в Monitor использует фиксированную ось 0–250 W
  для CPU/GPU. Аппаратный верхний предел больше не задаёт диапазон этой оси.
  Значения телеметрии и нормализация объединённого графика сохранены.
- Read-only режим и анимации сохранены.

[Overview](overview.png), [1024×768](overview-small.png),
[150%](scale150/overview.png), [Monitor с осью 250 W](monitor.png).

Проверки плотности/выравнивания и шкалы Power прошли после воспроизведения
прежнего поведения. Снимки создаются настоящими Qt Widgets с тестовым сервисом
на отдельной шине D-Bus.

Итоговая проверка: обе сборки успешны; CTest 16/16 в каждой, preview GUI audit
17 passed, отрисовка 150% 3 passed. `git diff --check` прошёл.
