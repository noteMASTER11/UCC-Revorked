# Плавное обновление Monitor

2026-10-03. Работа выполнена инлайн.

Временная шкала теперь обновляется отдельным таймером каждые 16 ms, между
опросами сервиса. Частота D-Bus опроса остаётся прежней: раз в 2000 ms.
Показ графика отстаёт на один интервал опроса (2 s), чтобы полученные реальные
отрезки раскрывались постепенно у правого края. Это указано в индикаторе Live.
Точки истории и пики не изменяются, сглаживание значений не применяется.

Отрисовка работает только для видимой активной страницы. Пауза, zoom и скрытие
останавливают движение; объединённый график использует тот же механизм.
При очистке истории сохраняется один предшествующий отсчёт, чтобы отрезок
достигал левого края окна. Показания hover и закреплённые отметки следуют за осью.

Регрессионный тест сначала воспроизвёл отсутствие движения между опросами.
После реализации проверены движение оси при неизменных точках, задержка,
пауза/возобновление, скрытие/показ, остановка и объединённый режим.
Обе сборки успешны; CTest 16/16 в каждой. Preview GUI audit: 13 passed.
`git diff --check` прошёл. Read-only gates сохранены.

## Blur сайдбара

Текущий процесс оконного менеджера — xfwm4. Приложение задаёт свойству окна
`_KDE_NET_WM_BLUR_BEHIND_REGION` прямоугольник сайдбара, но текущий композитор
не выполняет backdrop blur. Здесь результат — прозрачность, тонировка и зерно.
Подмена композитора и изменения настроек рабочего стола не выполнялись.
