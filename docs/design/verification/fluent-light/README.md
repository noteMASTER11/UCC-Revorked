## Реализовано

Пять страниц остаются на C++20 / Qt Widgets и Qt Charts. Общая светлая
палитра, боковая навигация, белые карточки, синий акцент, контурные
пиктограммы и переключатели заменяют прежнюю компоновку вкладок.
Параметры профилей и раскладки клавиатуры используют существующие данные
и обработчики; форматы сериализации не менялись.

## Привязка к референсам

- Overview: широкий блок активного профиля, CPU/GPU рядом, отдельные
  горизонтальные карточки охлаждения и аппаратных настроек.
- Profiles: внутренний список слева, команды сверху, редактор в карточках
  справа. Все прежние дополнительные поля доступны через прокрутку.
- Fan Control: выбор профиля и команды сверху, подстраницы System / Water
  Cooler, два широких редактора CPU/GPU один под другим.
- Monitor: Visible metrics слева, пять графиков справа, компактные легенды
  в правом верхнем углу, единая временная шкала и состояние Live / Paused.
- Keyboard: верхняя строка профиля, отдельная карточка схемы клавиатуры,
  яркость и цвет под ней, Hardware controls ниже.

Адаптации относительно концептов: Fan Control и Monitor переведены в
светлую палитру; используются реальные названия и возможности устройства.
Графики истории на Overview не добавлены: этот раздел получает текущие
значения. Переключатель одинаковой скорости вентиляторов сохранён в
системном профиле, которому он принадлежит в существующей модели данных.
При 1024×768 большие страницы прокручиваются вертикально. Пустые карточки
недоступных функций скрываются; подписи профиля переносятся на строки.

## Запуск промежуточного прототипа

Из корня репозитория:

```bash
./run-preview.sh
```

Скрипт конфигурирует `build-preview` с `UCC_READ_ONLY_PREVIEW=ON`, собирает
только `ucc-gui` и запускает его. Демон не запускается и не устанавливается.
Готовый бинарник: `build-preview/bin/ucc-gui`.

В этой сборке:

- команды изменения аппаратных параметров, применения, сохранения и
  удаления профилей отклоняются до отправки в D-Bus;
- прямые команды вентилятора, насоса и RGB охлаждения также отключены;
- выбор графиков и временного окна не сохраняет локальные настройки;
- GUI использует `com.uniwill.UccGuiPreview`, библиотеку
  `libucc-dbus-preview.so` и видимую отметку Read-only preview;
- синхронные чтения адресуются текущему уникальному владельцу службы,
  асинхронные чтения запрещают автоматическую активацию службы;
- при отсутствии демона или неподдерживаемом устройстве доступен просмотр
  интерфейса с недоступными данными.

Обычный `build/bin/ucc-gui` сохраняет штатные функции изменения настроек.
Для промежуточных проверок запускать `run-preview.sh`.

## Проверки

| Проверка | Результат |
| --- | --- |
| Debug, обычная сборка | Собрана; CTest 16/16 |
| Debug, read-only preview | Собрана; CTest 16/16 |
| Прямой запуск GUI audit preview | 11 passed, 0 failed, 0 skipped |
| Миграция конфигурации | 4 теста, OK |
| Пять страниц, 1280×900 и 1024×768 | Снимки получены, просмотрены |
| Масштаб 150% | Снимки получены; сценарий рендера прошёл |
| GUI без демона на частном D-Bus | Окно работает; процесс завершён таймаутом через 4 секунды |
| Зависимость preview-бинарника | readelf подтверждает libucc-dbus-preview.so.0 |
| Shell-скрипты и diff | bash -n и git diff --check без ошибок |

Audit проверяет отсутствие записей при отображении страниц и загрузке
данных, блокирование команд preview, сохранение значений при сбое чтения,
паузы и перекрывающиеся запросы, синхронизацию навигации, выбор нескольких
клавиш без изменения их цветов и отсутствие локальных записей настроек.
Регрессия подписи состояния охлаждения сначала воспроизведена падающим
сценарием, затем исправлена и проверена повторно.

Проверки выполнены на частном D-Bus без подключения к реальному оборудованию.
Физическое изменение подсветки, вентилятора и насоса не проверялось.
Hover, жесты zoom и все аппаратные раскладки требуют дальнейшей проверки
на целевом ноутбуке. Это не влияет на блокировку отправки команд в preview.

Во время проверки исправлены две сопутствующие проблемы: вызовы сигналов
при разрушении FanControlTab в Debug и запуск GJS-теста из пути с кириллицей.

## Воспроизведение

```bash
cmake --build build -j2
ctest --test-dir build --output-on-failure
cmake --build build-preview -j2
ctest --test-dir build-preview --output-on-failure
python3 contrib/mechrevo/tests/test_migration.py
UCC_SCREENSHOT_DIR="$PWD/docs/design/verification/fluent-light" \
  dbus-run-session -- bash tests/run_gui_audit_test.sh \
  build-preview/bin/test_gui_audit
QT_SCALE_FACTOR=1.5 UCC_SCREENSHOT_DIR="$PWD/docs/design/verification/fluent-light/scale150" \
  dbus-run-session -- bash tests/run_gui_audit_test.sh \
  build-preview/bin/test_gui_audit renderReferencePages
```
