# Аудит интерфейса — версия 2

Основание: REF1001–REF1005, снимок пользователя с CPU/GPU и отрисовка приложения.
Применены designly:composition-director, typography-director и visual-qa инлайн.

## Изменения

- CPU/GPU: общая сетка заголовков, моделей, температуры и основных показателей.
  Дополнительные GPU-данные расположены ниже и не сдвигают разделитель.
- Типографика: титул 28 px, секция 20 px, карточка 16 px, подзаголовок 14 px,
  основной текст 13–14 px. Метаданные приглушены; показатели выделены.
- Слайдеры: промежуток до чисел 24 px и колонка значений минимум 80 px.
- Profiles: единые поля и интервалы, устранены конфликты локальных шрифтов.
- Monitor: нейтральные подписи и отдельные цветовые маркеры без обрезания текста.
  Клавиатура: уменьшен вес цветных контуров клавиш.
- Cooler Settings и Watercool Settings вынесены в сайдбар; внутренние вкладки
  скрыты. Контролы водяного охлаждения собраны в форму.
- Сервис, охлаждение, активный профиль и временные сообщения перенесены в
  footer сайдбара. Нижний статусбар скрыт.
- Сайдбар: слабая прозрачность, тонировка и фактура. В X11 добавлен запрос
  `_KDE_NET_WM_BLUR_BEHIND_REGION` для собственной области окна.
  Текущий Xfce/xfwm4 не выполняет это размытие. На Wayland применяется материал
  без запроса blur. Настройки композитора не меняются.
- На графике устранён остаток подписи оси при текущем значении 100%.
