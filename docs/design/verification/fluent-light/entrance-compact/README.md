# Появление содержимого и компактный выбор профиля

2026-10-03. Выполнено инлайн, без делегирования.

## Компоновка Profiles

Вертикальная колонка списка удалена. Остаётся один существующий QComboBox
с идентификаторами профилей, теперь в верхней строке с Apply/Save/Copy/Remove.
Ширина селектора 180–360 px; видимый шеврон подчёркивает раскрытие меню.
Карточки редактора используют всю ширину. Верхняя строка остаётся на месте
при прокрутке настроек. Выбор загружает профиль; применение остаётся отдельным
действием. Переименование пользовательских профилей сохранено.

## Motion

Основание: [Fluent 2 Motion](https://fluent2.microsoft.design/motion),
[Microsoft Motion in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/motion).

- Оболочка страницы проявляется на месте за 120 ms.
- Карточки проявляются с подъёмом 8 px за 180 ms, easing OutCubic.
- Карточки одного ряда появляются вместе; следующие группы сдвинуты на
  20/40 ms. Полная последовательность занимает максимум 220 ms.
- Сайдбар остаётся неподвижным. Переход работает при показе окна, навигации
  между шестью разделами и выборе профиля для редактирования.
- Временный слой снимка не изменяет геометрию живых виджетов, не получает
  фокус и пропускает мышь. Быстрый переход заменяет предыдущую анимацию;
  изменение размера/скрытие отменяет её. После завершения снимок освобождается.
- `UCC_REDUCED_MOTION=1` отключает эффект; также учитывается
  `QStyle::SH_Widget_Animate`. Локальные настройки не записываются.
- Телеметрия не запускает повторные анимации появления. Плавная прокрутка
  Monitor и read-only gate сохранены.
